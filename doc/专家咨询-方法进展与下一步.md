## 1. 研究背景

本毕设基于 CVPR 2025 **LanCE（Language-guided Concept Erasing）**，主题为域泛化下的可解释图像分类。

**基础设定**：在 CLIP 文本编码器上构建概念瓶颈模型（CBM），图像特征 → 概念空间 → 类别预测。source 域（真实照片）训练，target 域（油画/剪贴画/雕塑等）测试。

**原论文方法 DDO（Domain Descriptor Orthogonality）**：
1. 用 200+ 个自然语言 prompt 描述域迁移方向（"a photo of a {}" → "a painting of a {}"）
2. 对每个 prompt pair，编码所有类别的文本嵌入，做差归一化得到域迁移方向 `diffs`
3. 投影到概念空间，过分类器得到 `regularizer`，正则损失 `orth_loss = |regularizer|.mean()`
4. 总损失：`L = cls_loss + α·orth_loss + β·concept_loss`

直觉：让分类器对"域迁移方向"不响应，抹除域相关概念，提升 OOD 泛化。

## 2. 第一轮创新与困境（第一次咨询前）

### 2.1 我的创新：Reliability-Weighted DDO

**动机**：DDO 对所有 prompt 一视同仁，但有些 prompt 描述的迁移质量高、有些是噪声。

**度量**：对每个 prompt pair，用**类间迁移方向一致性**衡量可靠性——同一 prompt 在不同类别上产生的迁移方向越一致，说明它描述的域迁移越"本质"。

完整计算（对每个 (source_prompt, target_prompt) pair）：

```python
# 1. 编码所有类别的 source/target 文本嵌入 (CLIP text encoder)
source_emb = encode_text([src_prompt.format(c) for c in classes])   # (K, D)
target_emb = encode_text([tgt_prompt.format(c) for c in classes])   # (K, D)
source_emb /= source_emb.norm(dim=-1, keepdim=True)
target_emb /= target_emb.norm(dim=-1, keepdim=True)

# 2. 域迁移方向: target - source, 逐类归一化
diffs = (target_emb - source_emb) / (raw_diffs.norm(dim=-1, keepdim=True) + eps)  # (K, D)

# 3. reliability = 类间迁移方向的平均 cosine 相似度 (去对角线)
cos_sim = diffs @ diffs.T                        # (K, K)
reliability = cos_sim[~torch.eye(K, dtype=bool)].mean()   # 标量, 越大越"一致"
```

**原始加权**：median 二值化（HIGH/LOW 两档），实验中在 4 个数据集变体上用了 3 套手调值（1.8/0.75、1.5/0.5、1.25/0.75）。

### 2.2 三个困境（上次咨询的核心问题）

- **困境 A**：二值化丢失连续信息
- **困境 B**：阈值与双值手调，跨数据集不泛化
- **困境 C（最根本）**：可靠性 ≠ 有效性——方向一致的 prompt 未必对 target 泛化有益

## 3. 专家建议的最终框架（已实现）

第一次咨询中专家确定：**Reliability Prior + Learnable Residual + KL 正则**。

### 3.1 方法设计

```
prior     = reliability_scores   (detach, buffer, 不更新 —— 归纳偏置)
residual  = nn.Parameter(zeros)  (初始 0, 随训练学习 —— 数据驱动修正)

logits  = prior + residual
weights = softmax(logits) × N               (均值=1, 保持 orth_loss 量级)

KL 正则 = log N − entropy(softmax(residual)) = D_KL(softmax(residual) ‖ uniform)

total_loss = cls_loss + α·orth_loss + β·concept_loss + λ_kl·KL    (λ_kl=0.01)
```

**关键性质**：
- **训练初期**：residual=0 ⇒ weights = softmax(prior)×N，等价于连续软加权，reliability 先验主导
- **训练后期**：residual 学习，权重被数据驱动修正；KL 约束 residual 不偏离 uniform 太远（防退化，连续可导，有概率解释——专家否定了原方案的 clamp(min=0.3)）
- **对困境 C 的回应**：权重随分类目标学习，自动降低"一致但无效" prompt 的权重；reliability 只提供起点归纳偏置，不是最终答案

### 3.2 关键代码实现（全部完成）

**① 模型侧：Prior + Residual**（`model/cbm_models.py` `clip_cbm_orth`，DDO 模型基础上新增）：

```python
def __init__(self, ..., domain_diffs, domain_weights=None, ...):
    # domain_weights 传入的是 reliability_scores (prior_residual 策略下透传)
    self.num_prompts = domain_diffs.size(0)
    if domain_weights is None:
        self.reliability_prior = None
        self.domain_residual = None
    else:
        prior = domain_weights.clone().float().to(self.device).detach()
        self.register_buffer('reliability_prior', prior)      # 先验: buffer, 不随梯度更新
        self.domain_residual = nn.Parameter(torch.zeros_like(prior))  # 残差: 初始 0
    # ... 其余与原 DDO 相同 (concept_embeddings, classifier, domain_concept_projection)

def get_domain_weights(self):
    """返回 (最终权重, residual 的 softmax) — 后者供 KL 正则使用"""
    logits = self.reliability_prior + self.domain_residual
    weights = torch.softmax(logits, dim=0) * self.num_prompts   # 均值=1, 保量级
    residual_softmax = torch.softmax(self.domain_residual, dim=0)
    return weights, residual_softmax

def forward(self, images):
    # ... 概念激活、分类 logits 与原 DDO 完全一致 ...
    regularizer = self.classifier[1:](self.domain_concept_projection)  # (N, K, C)
    weights, _ = self.get_domain_weights()
    if weights is not None:
        regularizer = regularizer * weights.view(-1, 1, 1)     # 权重注入 (逐 prompt)
    return concept_activations, self.classifier(concept_activations), regularizer
```

**② 训练侧：KL 正则 + 总损失**（`main.py` `_train_epoch`）：

```python
concept_preds, cls_preds, reg_loss = self.model(images)
cls_loss  = CE(cls_preds, labels)
orth_loss = torch.abs(reg_loss).mean()

# KL 正则: D_KL(softmax(residual) ‖ uniform) = log N − entropy
# residual=0 时 softmax=uniform, KL=0; residual 偏离 uniform 时 KL>0
_, residual_softmax = self.model.get_domain_weights()
N = residual_softmax.size(0)
entropy = -(residual_softmax * (residual_softmax + 1e-8).log()).sum()
kl_loss = torch.log(torch.tensor(float(N))) - entropy

total_loss = cls_loss + alpha * orth_loss + beta * concept_loss + lambda_kl * kl_loss
#                                                                    ↑ 默认 0.01, 命令行可调
```

**③ 数据侧：可复用模块**（`reliability.py`，6 个数据集文件共用一行调用）：

```python
# 在任意 Dataset.__init__ 中 (算完 classname2id 之后):
attach_domain_reliability(
    self, clip_model, src_dm_texts, tgt_dm_texts,
    class_names=list(self.classname2id.keys()),
    device=device,
    weight_strategy="prior_residual",   # "binary"(复现旧实验) | "soft"(消融) | "prior_residual"(主方法)
)
# 自动挂载: self.domain_diffs / self.reliability_scores / self.domain_weights
```

**工程收益**：原实现把同样的可靠性逻辑复制在 6 个数据集文件里（且 4 个变体用了 3 套手调值）；现在统一为模块调用，切换策略只改一个字符串，新数据集零成本接入。

## 4. 请教一：第三章还可补充哪些小创新点？

我 brainstorm 了一些候选，按"工作量×收益"排序，请专家帮忙挑选/增删：

### 候选 A：Residual 学习轨迹可视化（几乎零成本，可解释性卖点）
训练过程中定期记录 `residual` 与最终权重，画热图/曲线：**哪些 prompt 的权重被数据显著修正？被上调/下调的 prompt 在语义上有什么共性？**（如 painting 类上调、抽象类下调）。这直接支撑"数据驱动修正"的论述，也是答辩的好图。

### 候选 B：Reliability 分布的语义分析（零成本，数据侧分析）
统计 204 个 prompt 的 reliability 分布，按语义类别（绘画系/素描系/雕塑系/抽象系…）分组比较，验证"reliability 高的 prompt 确实语义上更接近真实域迁移"。可作为方法动机的实证支撑（第三章开头的小节）。

### 候选 C：可学习温度 τ（小成本）
`weights = softmax((prior+residual)/τ) × N`，τ 为可学习标量，控制权重分布锐度。比手调双值更 principled，可与主方法叠加，多一组消融。

### 候选 D：多特征融合的 reliability（中成本，专家上次提过）
把单一"类间方向一致性"扩展为多特征：方向一致性 + prompt 嵌入语义多样性 + 与 source prompt 的文本相似度，用小 MLP（1→8→1）学习融合。论文重点从"如何加权"升级为"如何评价 prompt 质量"。风险：特征设计需要实验支撑。

### 候选 E：residual 退火 schedule（小成本）
训练初期锁定 residual=0（纯先验），随 epoch 线性/余弦放开。动机：先训练出合理的分类器后再让权重参与调整，避免早期噪声梯度污染 residual。类似 warmup。

### 候选 F：KL 正则的变分解释（纯写作，理论小节）
从"权重后验近似"角度给 KL 正则一个变分推断视角的推导，提升方法章节的理论感。

**我的初步倾向**：A + B 必做（零成本高收益）；C 或 E 选一个做小消融；D 作为"未来工作"或时间充裕时的扩展。
