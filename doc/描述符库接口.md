# 描述符库接口：现状审查与工程准备

2026-11-26，外审第九轮 P4（"新描述符库的工程接口审查与准备"）。**本轮只做工程准备：不生成新词库，不做新词库的训练，Original-204 保持不变。**

## 1. 现状核实（2026-11-26；`descriptor_bank_audit.py` 的输出见 `experiment_results/DescriptorBank/descriptor_bank_audit.md`）

**训练实际使用的词库**：`prompts/prompt200new.py` 的两个列表，下文称 **Original-204**。

| 项 | 值 |
|---|---|
| 源模板 `source_text_prompts` | 1 条：`a photo of a {}.` |
| 目标模板 `target_text_prompts` | 204 条，每条恰好含一个 `{}`（类别名占位符） |
| 身份（完整文本按 NUL 连接后的 sha256） | 源 `e8e367e7…`；目标 `1f55c2a9…`；词库 `bc4ba710…` |
| 文件 sha256 | `ce8d5e81…` |

**同目录的另外两个词库**（不用于训练）：`prompts/prompt.py`（130 条目标模板）、`prompts/prompt200.py`（210 条，**含重复条目**：`a quickdraw of a {}.` 出现两次，索引 57）。

**描述符如何进入模型**（`reliability.attach_domain_reliability` → `compute_domain_diffs_and_scores`）：对第 i 对 (源模板_i, 目标模板_i)，把类别名代入两个模板、用 CLIP 文本编码器编码全部类别，做差并归一化，得到 `domain_diffs[i]`（C × 768）；可靠性分数 = 类间迁移方向的平均余弦。共 204 × C 个方向。模型里 DDO 约束的方向是 `u_ij = LN0(E · d_ij)`（E 为冻结的概念矩阵），语言域椭球用的是这些方向的非中心化二阶矩。**所以词库同时决定 DDO 的约束对象与语言域椭球的几何。**

**可靠性缓存**（`cache/reliability/reliability_<键>.pt`，被 gitignore）：

- 旧键（2026-11-26 之前）= md5(源模板 + 类别名（实际顺序）+ 目标模板) 的前 16 位。**不含 CLIP 权重身份，也不含概念表**；代码注释写明"项目实际只用 ViT-L-14.pt，更换 CLIP 后需手动清缓存"。
- 新键 = 旧键的三个文本序列 + 概念名（名称与顺序）+ CLIP 权重文件的 sha256。完整文本、顺序、类别表、概念表、CLIP 版本都在键里，新旧词库的缓存不会串用。
- 旧缓存文件的认领：按旧键能找到文件时直接沿用其数值（不重算），并在缓存里写明 `legacy_adopted = True` 与认领时假定的 CLIP 身份。**这是基于"旧缓存都由同一份 ViT-L-14.pt 产生"这一既有事实的假定**；对 CUB 做过一次重算核对（见审计记录），其它数据集没有重算核对。这样做的目的是让既有实验的训练路径逐位不变。

| 文件 | 可复用的部分 | 不能继承的部分 |
|---|---|---|
| `prompts/prompt200new.py` | Original-204 本身（两个列表）。**保持不变。** | — |
| `prompts/prompt200.py` | 历史对照（210 条、含重复）。加载入口的校验器会拒绝加载它。 | 不用于任何训练 |

| `descriptor_selection.py` | 约 600 条候选池 `build_pool()`（纯文本，可复用为候选来源） | 第 222–238 行用**目标域测试集的特征缓存**（`class_conditional_real(src_c, tgt_c)`）评价描述符子集——只能当事后分析，**不能作为 source-only 的筛选依据** |
| `language_ellipsoid.py` | 由域方向构造语言域椭球（`domain_directions`、`second_moments`、`build_ellipsoids`） | — |
| `utils.get_domain_text_embs` | 模板代入类别名后用 CLIP 编码 | — |

## 3. 新增的工程接口

- **`descriptor_bank.py`**（新）：统一加载入口。
  - `--descriptor_bank original`（默认）：Original-204，与原来的硬编码导入逐条相同。
  - `--descriptor_bank <路径>.json`：冻结格式的词库文件（格式见文件的文档字符串：`id` / `version` / `created` / `generator` / `generation_record` / 两个模板列表 / 可选的 `descriptor_categories`）。
  - `--descriptor_bank <路径>.py`：含两个列表的 Python 文件。
  - 校验：每条模板必须是非空字符串、恰好含一个 `{}`、不重复；类别标注长度必须等于描述符数。任何一条不满足就报错，不静默回退。
  - 词库身份 `bank_sha256` = 两个列表的完整文本（含顺序）的 sha256，进入缓存键，并写进结果 json 的 `run_config`。
- **`args.py`**：新增 `--descriptor_bank`（默认 `original`）。结果 json 的 `run_config` 里能看到每个 run 用的是哪一份词库。
- **`data/__init__.py`**：六个数据集都从统一入口取模板，不再硬编码导入 `prompt200new`。
- **`reliability.py`**：缓存键改为新键；缓存文件里写入 `meta`（词库身份、类别表、概念表、CLIP 身份、是否认领自旧缓存）。
