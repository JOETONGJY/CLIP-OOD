### 1.1 核心创新

基于 LanCE 论文的 DDO（Domain Descriptor Orthogonality）正则化器，提出 **Reliability-Weighted DDO**：

- **可靠性先验（Prior）**：用类间迁移方向一致性衡量每个 prompt 的可靠性
- **可学习残差（Residual）**：在先验基础上学习修正项，数据驱动调整权重
- **KL 正则**：约束残差不偏离 uniform，防止退化

```
prior = reliability_scores (detach, buffer, 不更新)
residual = nn.Parameter(zeros)  (初始 0, 随训练学习)

logits = prior + residual
weights = softmax(logits) * N          # 均值=1, 保量级

KL 正则 = log(N) - entropy(softmax(residual)) = D_KL(softmax(residual) ‖ uniform)
total_loss = cls_loss + α·orth_loss + β·concept_loss + λ_kl·KL
```

## 六、消融实验设计

| 实验组 | weight_strategy | prior | residual | λ_kl | 说明 |
|---|---|---|---|---|---|
| Baseline (原 DDO) | - | 无 | 无 | - | `--CBM_type cliplp` 或不传 domain_diffs |
| 方案 1 (软加权) | `"soft"` | - | - | - | 纯 reliability，无可学习 |
| 无先验 | `"prior_residual"` | 0/uniform | ✓ | 0.01 | residual 从零开始，无 reliability 先验 |
| 仅先验 | `"soft"` | - | - | - | 等价方案 1，residual 不学习 |
| **主方法** | `"prior_residual"` | reliability | ✓ | 0.01 | **Prior + Residual + KL** |

### 切换策略

所有数据集文件中（`data/CUB/cub_data.py` 等）的 `weight_strategy` 参数：
- `"prior_residual"`：主方法（默认）
- `"soft"`：方案 1 软加权（消融对比）
- `"binary"`：旧的手调二值化（复现旧实验）

切换时改数据集文件里的 `weight_strategy="xxx"` 即可，无需改其他代码。

### 无先验消融

在 `model/cbm_models.py` 中把 `reliability_prior` 置零：
```python
# 临时改: prior = torch.zeros_like(...)
self.register_buffer('reliability_prior', torch.zeros_like(prior))
```

## 八、权重机制详解

### 8.1 数据流

```
数据集 __init__
    │
    ├── attach_domain_reliability()
    │       ├── compute_domain_diffs_and_scores()  → domain_diffs, reliability_scores
    │       └── make_weights_prior_residual()      → domain_weights (= scores, 透传)
    │
    ▼
model clip_cbm_orth.__init__
    │
    ├── register_buffer('reliability_prior', scores.detach())  # 先验, 不更新
    ├── nn.Parameter('domain_residual', zeros)                 # 残差, 可学习
    │
    ▼
model forward()
    │
    ├── get_domain_weights()
    │       ├── logits = prior + residual
    │       ├── weights = softmax(logits) * N                  # 均值=1
    │       └── residual_softmax = softmax(residual)           # 供 KL 正则用
    │
    ├── regularizer = classifier(domain_concept_projection)
    ├── regularizer = regularizer * weights.view(-1,1,1)
    │
    ▼
main.py _train_epoch()
    │
    ├── orth_loss = |regularizer|.mean()
    ├── kl_loss = log(N) - entropy(softmax(residual))
    └── total_loss = cls_loss + α·orth_loss + β·concept_loss + λ_kl·kl_loss
```

### 8.2 训练过程权重变化

- **训练初期**：residual=0，`weights = softmax(prior)*N`（等价方案 1 软加权，reliability 先验主导）
- **训练后期**：residual 学习，weights 被数据驱动修正
- **KL 正则**：约束 residual 不能偏离 uniform 太远（防止退化到"全压一个 prompt"）

### 8.3 验证结果

mock CLIP 嵌入全链路验证通过：
- 初始 `weights == softmax(prior)*N` ✓
- KL 正则初始=0，偏离 uniform 时>0 ✓
- residual 梯度正常流动 ✓
- 9 个文件语法 + import 通过 ✓
