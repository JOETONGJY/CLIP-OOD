## 0. 统一记号

- 分类头：`h(u) = W·(γ ⊙ LN(u)) + W·β + b`，即 `nn.Sequential(Flatten, LayerNorm(K), Linear(K, C))`；K=312（CUB 的概念数），C=200。
- **有效方向响应** `A = W ⊙ γ ∈ ℝ^{C×K}`（行向量按类），**有效偏置** `c = W·β + b ∈ ℝ^C`。对任意输入 x：`h(x) = A·LN(x) + c`。
- 域方向：`u_{i,c} = LN0(E·d_{i,c}) ∈ ℝ^K`（无 affine 的 LayerNorm；N=204 个描述符 × C 个文本类别）。**所有 u 恒位于零均值超平面 H：1ᵀu = 0**，其行范数 ≈ √(K−1)（有偏方差下为 √K 量级）。
- `H = I − (1/K)·1·1ᵀ`：零均值超平面的正交投影。

## 1. Stage 0A：偏置吸收诊断（零训练）

**问题**（R 方向 4）：原始 DDO 惩罚的是 `A·u + c`。优化器可以让 `c ≈ −A·ū`（ū 为 u 的均值方向）来"凭空"抵消最主要的域偏移；而真实测试时偏移作用在样本的概念激活上，`c` 在类别差 `(h_y − h_k)` 中会消去——文本侧的抵消在视觉侧不存在。

**指标**（R 第 1 步；G3 第 5 节的限定）：
- `cos(c, A·ū)` 与幅值比 `‖c‖ / ‖A·ū‖`；均值能量占比 `η_mean = ‖μ‖² / E‖u‖²`（μ = E[u]，非中心化）。
- 对照链：Original → Full-Symmetric → Bias-Free。**G3 的限定**：Bias-Free 不直接惩罚 β、b，但 W、γ 仍在更新，有效截距 `c = Wβ + b` 在训练中仍可能变化；只能说"解除了对截距项的直接惩罚"。
- **递进关系**（C 细节 4）：`(1/2)(|Au+c| + |−Au+c|) = max(|Au|, |c|)`。Full-Symmetric 堵住了"c 反向抵消 A·μ"，但仍惩罚 `|c|`；Bias-Free 两者都不做。

**所需模型**（G4）：正式矩阵都是 `--no_save_model`，没有收敛的分类头。**另跑少量预先确定的配置并保存分类头**：CE-Only（α=0）、Full DDO（α=1、2）、Mean（α=1、2）、Full-Symmetric（α=1、2），各 3 seeds。

## 2. Stage 0B：概念脆弱抵消诊断（零训练）

**问题**（R 方向 2）：DDO 只要求概念贡献的**加权和**为零：`Σ_j A_{c,j}·u_j ≈ 0`。模型可以不放弃域敏感概念，只给两个域敏感概念赋予相反的大权重让它们在**文本域方向上**互相抵消。但 P0 诊断显示语言域子空间对真实视觉偏移的覆盖只有 10.4%～26.0%，到真实目标域时这种抵消会失效。

**三层问题**（G4 第五轮）：
1. 现象是否存在？—— CR / CI / PCR / 绝对贡献能量
2. 抵消是否脆弱？—— 文本方向的低响应是否在源域视觉增强下失效
3. 脆弱性是否可改善？—— 结构保持型收缩协方差的干预实验（不是只看相关性）

**指标**（C 细节 2 + G3 第 2 节的修正）。记 `a = A_y ⊙ u`（某方向 u 在第 y 类上的逐概念贡献）：
- `CR = E[Σ_j |a_j|] / E[|Σ_j a_j|]`（R 原始定义；分母接近 0 时不稳定）
- `CI = 1 − E|Σ_j a_j| / (E Σ_j |a_j| + ε)`（G3 的有界版本）。**缺陷**：随机基线天然在 `1 − O(1/√K)`（K=312 时约 0.94），高维饱和、不可跨数据集比较。
- `PCR(w) = wᵀ G w / wᵀ D̃ w`，`D̃ = (K/(K−1))·H·diag(G)·H`（C 细节 2）。性质：
  - **迹守恒** `tr(D̃) = tr(G)`（对零均值超平面内的 u 精确成立——已数值验证）。
  - **G3 的修正**：随机权重下只保证 `E[分子]/E[分母] = 1`，**不保证 `E[PCR] = 1`**（期望的比值 ≠ 比值的期望；数值验证：期望之比 1.0001，比的期望 0.9994）。所以 **PCR 必须配随机经验基线**（零均值超平面内的各向同性随机权重，报告其分布而不是拿 1.0 当阈值）。
  - 同时保留 **PCR-Pair**（单个竞争类别对）与 **PCR-Global**（所有预定义类别对的能量先求和再取比），**报告分子与分母**，不只报比值。
- `G = E[u uᵀ]`，**非中心化二阶矩**（C 细节 1）。u 是 `target − photo` 的差分向量，其均值 μ 就是"离开照片域"的公共迁移方向；若按惯例中心化，会把这条最核心的轴从椭球里抹掉。保留 **Centered Cov 对照**（G3：不预设均值偏移一定有益）。**记号用 G，不用 M₂**（避免与 M1–M4 四层方向矩阵混淆）。
- **决策级诊断**用有效类别权重差 `w_{yk} = γ ⊙ (W_y − W_k)`，避免公共 logit 分量的影响。

**视觉扰动敏感性**（G4）：只有当概念抵消能够**预测**源域视觉扰动下的决策脆弱性时，才支持进一步开发概念鲁棒收缩。

**实现时发现的两点（2026-11-25，材料里没有；`concept_cancellation.py` 的合成数据自测与真实 CUB 的 G 上实测）**：

1. **PCR 的随机基线在真实的 CUB 上很宽，而且中位数不是 1。** 对真实 `G`（非中心化，40800×312）取 40000 个超平面内的各向同性随机权重：中位数 **0.80**，5%～95% 区间 **[0.36, 2.34]**，标准差 0.68；"期望之比"是 1.001（这一条确实成立）。宽度来自 `diag(G)`：最大值是中位数的 **10.4 倍**——分母参考被少数几个高度域敏感的概念主导，随机权重落在它们上面多一点，PCR 就低很多。合成数据上还看到基线宽度随谱的陡峭度增大（协方差对角时标准差 0.007，随机旋转成非对角后 0.046）。**后果**：不能拿 1.0 当阈值；**单个类别对的 PCR 几乎没有判别力**，要看一批类别对相对经验分布的分位数，或 PCR-Global。判定用 `pcr_quantile`（在经验分布中的分位），不用固定阈值。
2. **PCR 低 ≠ 脆弱抵消。** "抵消型"（两个同相变化的域敏感概念配 +a/−a）和"放弃型"（完全不用域敏感概念）的 PCR 都低（合成数据上 0.048 与 0.138），区别在**绝对依赖能量**：抵消型是同范数随机权重的 7.0 倍，放弃型是 0.15 倍。所以判定"脆弱抵消"需要三件事同时成立：PCR 在基线低尾、CI 高、依赖能量高于随机。这正是 C 文件三态图里状态 B 与状态 C 的区别，以及 G3 "PCR 不是越高越好也不是越低越好"的含义——实现上把它落成了可计算的量。
3. （合成数据构造上的一个教训）"脆弱抵消"只在域敏感概念**同相变化**时才成立；若各概念在域方向上独立变化，+a/−a 不构成抵消，指标也正确地不报。

## 6. Stage 1C：LD-DRO 独立原型

### 6.1 数学

**椭球**（R 方向 1，G3 改用低秩生成式避开奇异协方差求逆）：`E_ε = {L q : ‖q‖₂ ≤ ε}`，`Σ = L Lᵀ`，`L ∈ ℝ^{K×r}`。

**逐竞争类最坏间隔的闭式解**（精确；已数值验证）：
```
min_{δ∈E_ε} [(W_y − W_k)ᵀ(γ⊙(x+δ)) + (b_y − b_k)] = (ℓ_y − ℓ_k) − ε·‖Lᵀ(A_k − A_y)ᵀ‖₂
```
其中 `A = W ⊙ γ`。**β 与 b 在类别差中严格消去**，公共 logit 分量也消去。

**LD-DRO 交叉熵**（R 方向 1）：
```
L_LD = −log( e^{ℓ_y} / (e^{ℓ_y} + Σ_{k≠y} exp(ℓ_k + ε·r_yk)) ),   r_yk = ‖M_k − M_y‖₂,  M = A·L ∈ ℝ^{C×r}
```
**G3 的定位修正**：逐对最坏间隔是精确的，但这个交叉熵形式是"**共享扰动下最坏交叉熵的闭式上界**"，不是精确解——多个竞争类的最坏扰动不一定是同一个 δ。

### 6.2 对照臂（G4 第五轮在 G3 的基础上新增两臂）

| 臂 | Σ | 验证目的 |
|---|---|---|
| CE-Only | — | 无鲁棒约束基线 |
| Full-DDO | — | 原始方法基线 |
| LD-Identity | `H/(K−1)`（迹 1，限制在零均值超平面） | 通用鲁棒分类间隔 |
| LD-Random-SpecMatched | `Q Λ_lang Qᵀ`，Q 为 H 内的随机正交基 | 同谱随机几何 |
| LD-Language-Full | `V Λ Vᵀ`，完整语言二阶矩（r = 数值秩） | 完整语言域结构 |
| LD-Language-32 | 截断到 r=32（先截断再迹归一化） | 低秩语言椭球 |
| Language-ISDA | 同 Language | 期望扰动损失的 Jensen 上界 |
| Language-PGD | 同 Language | 共享扰动的数值优化对照 |

**新增 Full 与 32 区分的理由**（G4）：DDO-Subspace 已表明谱截断可能产生严重负作用，不能再默认低秩椭球保留完整语言域结构的有效信息。

### 6.3 实现规格

**椭球构造**（C 细节 3.1 + G3）：
- Language：`Σ_lang = V Λ Vᵀ`，迹归一化为 1。**先截断、再迹归一化**。
- Random-SpecMatched：`Σ_rand = Q Λ_lang Qᵀ`，`H Q = Q`。**必须与 Language 有完全相同的截断谱、秩和迹**，唯一不同的是特征向量方向。
- Identity：`Σ_id = H/(K−1)`。Identity 是满秩超平面矩阵，Language/Random 可能是截断低秩——**另留一个 Random-Flat 可选对照**，区分"低秩本身"与"非均匀谱分布"。
- 保存矩阵摘要哈希与随机种子。
- **G3**：相同的迹不等于相同的最大扰动强度，仍需半径扫描与梯度诊断。

**损失与数值**（C 细节 3.2 + G3）：
- LD-DRO：`ℓ̃_k = ℓ_k + ε·r_yk`（k≠y）；`r_yk = sqrt(‖M_k − M_y‖² + 1e−8)`；**对角线 k=y 显式 mask 置 0**（防 `sqrt(0)` 的 NaN 梯度）。
- ISDA：`ℓ̃_k = ℓ_k + (λ/2)·r_yk²`（高斯扰动 `δ ~ N(0, λΣ)` 的 Jensen 上界）。ISDA 原论文用线性 warmup `λ(t) = (t/T)·λ₀`；同时测固定 λ 与 warmup，按初始平均间隔惩罚量级对标 ε。**G3：平方距离项无需开根号。**
- PGD：`ℓ(u + Lq) = ℓ(u) + M q` 对 q 仿射，CE 对 q 是凸函数。
  - **G3 的修正**：凸函数的**最大化**不保证 PGD 找到全局最优。成立的是链 `CE(0) ≤ L_PGD,best ≤ L_worst ≤ L_LD`。**PGD 实现必须把零扰动纳入候选，并保留搜索过程中的最大损失。**
  - 两种配置：PGD-5（轻量训练对照）；PGD-50 + 多次随机重启 + 以各竞争类闭式最坏方向为起点（独立评估上界紧致度）。
  - 报告 `Δ_gap = L_LD − L_PGD,best`，它是**上下界之间的差距**，不是已知真值后的精确误差。
- **G3**：LD-DRO 与 ISDA 在扰动半径/强度为 0 时必须退化为 CE-Only；用稳定的 `cross_entropy` / `logsumexp`，不直接算指数分母。

### 6.4 结论边界（G3 第 4 节）

- LD-DRO 的扰动发生在 **LayerNorm 后、affine 前的概念空间**，满足零均值约束，但不一定满足真实 LayerNorm 输出的范数约束与视觉特征可达性约束。
- 现阶段应定位为"**语言引导的概念空间扰动鲁棒性方法**"，**不能直接声称对真实图像域偏移提供严格的鲁棒保证**。需通过 source-only 视觉增强诊断其扰动模型的实际合理性（Stage 0D）。

### 6.5 实现时发现（2026-11-25，`ld_dro.py` 的 21 项合成数据自测；材料里没有）

1. **闭式上界随 ε 增大而变松。** 同一批数据上 `L_LD − L_PGD-50(4 次重启)` 的差：ε=0.05 时 0.035，ε=0.2 时 0.119，ε=0.5 时 0.255。链 `CE(0) ≤ PGD-5 ≤ PGD-50 ≤ LD` 在三档都成立，但 PGD-5 比 PGD-50 低 0.01～0.07，说明 5 步 PGD 在大 ε 下也没收敛。**后果**：ε 扫描里大 ε 的负结果不能直接读作"语言域约束无效"——可能只是上界太松；必须同时报告同 ε 的 PGD 值与 gap。这也说明 Stage 1C 里 PGD 不只是"对照"，是解释 LD-DRO 结果的必要参照。
2. **"最坏间隔的闭式解"与"闭式交叉熵"的精度不同**：前者与数值最大化在合成数据上吻合到 10⁻⁵（逐竞争类精确），后者是上界。实现时两者要分开表述，不能因为前者精确就称后者精确。
3. **实现细节（已钉成测试）**：`h(u) = A·u + c` 里的 `u` 必须是已归一化的向量（对原始输入不成立）；对角线置零必须是**按样本**的真实类位置 `(b, y_b)`，不是一个共享的单位阵；PGD 要逐样本求最坏（`reduction='none'`），与 LD-DRO 的逐样本形式一致。
4. **合成数据上四个对照椭球的 LD 损失很接近**（6.247～6.270，相差不到 0.4%）——那里的分类头是随机初始化的，不足为据；但它提醒：真实实验中各对照臂的差异可能不大，ε 的量程要事先按"初始平均间隔惩罚"标定（C 细节 3.2 的要求），否则差异会淹在噪声里。

## 7. 明确不做的事

- **Fisher-Spectral 往后排**（G3）：避免与第四章 SRDA 在"语义保护域子空间"上撞车；且 G4 指出主方向与类间/类内散度的捕获比例相近，判别保护不能只看 B、还要看 W。
- **不扩大子空间实验分支**（G5）。主线 A 的 DDO-Dose / Subspace / Projected-Residual-Split / Bias-Free 分量对照已共 240 个 run。
- **TU-DDO 降级**（R）：只要输出还是 204 维标量权重，就绕不开低有效秩的天花板；视觉增强代理更划算的用途是选低维超参（ε、ρ、k）。
- **CA-DDO / MSR-DDO 保持暂停**（R）。
