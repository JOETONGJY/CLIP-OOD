## 第四章方法链（术语已冻结）

**Domain Structure Discovery → Adaptive Subspace Construction → Soft Domain Suppression → Invariant Classification**

数学定义（完整四步）：

1. **Domain Structure Discovery**：类平均 prompt 方向归一化堆叠 $D\in\mathbb{R}^{N\times d}$，SVD：$D=U\Sigma V^\top$
2. **Adaptive Subspace Construction**：累计解释能量 $CE(m)=\frac{\sum_{i\le m}\sigma_i^2}{\sum_{i\le r}\sigma_i^2}$，$m(\tau)=\min\{m:CE(m)\ge\tau\}$，$B=[v_1,\dots,v_m]$，projector $P_D=BB^\top$
3. **Soft Domain Suppression**：$z_{inv}=(I-\gamma P_D)z$，$\gamma=\sigma(a)\in(0,1)$。**hardproj/softproj 是统一公式的边界情况**（γ=1 / 可学习γ）
4. **Invariant Classification**：$\hat y = h_{inv}(z_{inv})$（训练 $L=CE(h_o(z))+\lambda_{inv}CE(h_{inv}(z_{inv}))+\alpha L_{DDO}$，测试只用 $h_{inv}$）

消融组对应：当前 `softproj` 单头在 z_inv 上 ≡ 专家建议的 "SoftProj + Shared Head" 消融（区分"多头收益"vs"投影后需要适配的头"），无需新增代码。

## 1. 项目背景（一段话）

毕设基于 CVPR 2025 LanCE。CLIP 上构建概念瓶颈模型（CBM），source 域（照片）训练、target 域（油画/剪贴画/雕塑）测试。原方法 **DDO** 用 200+ 个语言 prompt 描述域迁移方向，约束分类器对这些方向"正交"（不响应），提升 OOD 泛化，但对所有 prompt **等权**。

## 2. 第三章方法（两轮咨询定型，已实现）

### 2.1 完整链条

```
DDO 等权 → Reliability-aware → Prior + Residual → KL 正则
```

核心命题：**Reliability ≠ Effectiveness**——类间迁移方向一致性只能证明"prompt 形成稳定方向"，不能证明"该方向对 OOD 分类有益"；Prior+Residual 正是在不丢弃 reliability 的前提下让数据修正它。

### 2.2 方法公式

```
prior     = reliability_scores   (detach buffer, 不更新 —— 归纳偏置)
residual  = nn.Parameter(zeros)  (随训练学习 —— 数据驱动修正)

logits  = prior + residual
weights = softmax(logits) × N                (均值=1, 保持 orth_loss 量级)

KL 正则 = log N − H(softmax(residual)) = D_KL(softmax(residual) ‖ uniform)

total_loss = cls_loss + α·orth_loss + β·concept_loss + λ_kl·KL     (α=1, λ_kl=0.01)
```

（第二轮咨询中专家指出的 KL 方向表述错误已全局修正为 `D_KL(q‖U)`，q=softmax(residual)。）

### 2.3 核心代码（已实现）

**可靠性计算**（对每个 prompt pair，数据集初始化时离线算一次）：

```python
# 编码所有类别的 source/target 文本嵌入, 做差归一化得域迁移方向 diffs (K, D)
diffs = (target_emb - source_emb) / (||target_emb - source_emb|| + eps)

# reliability = 类间迁移方向的平均 cosine 相似度 (去对角线)
cos_sim = diffs @ diffs.T
reliability = cos_sim[~torch.eye(K, dtype=bool)].mean()   # 标量
```

**模型侧四种模式**（一开关覆盖论文全部 4 组核心实验）：

```python
def __init__(self, ..., domain_diffs, domain_weights=None, weight_mode="prior_residual"):
    # domain_weights = reliability_scores (数据集侧统一透传原始分数)
    # weight_mode: none=原DDO | fixed=软加权 | residual=无先验 | prior_residual=主方法
    if domain_weights is None or weight_mode == "none":
        self.reliability_prior, self.domain_residual = None, None
    elif weight_mode == "fixed":                      # Soft Reliability: 固定权重
        fixed_w = softmax(scores) * N                 # buffer, 不可学习
    else:                                             # residual 或 prior_residual
        if weight_mode == "residual": scores = zeros  # Residual Only: 先验置零
        self.register_buffer('reliability_prior', scores.detach())  # 先验: 梯度不可达
        self.domain_residual = nn.Parameter(torch.zeros_like(scores))  # 残差: 从零学

def get_domain_weights(self):
    logits = self.reliability_prior + self.domain_residual
    weights = softmax(logits, dim=0) * self.num_prompts      # 均值=1
    return weights, softmax(self.domain_residual, dim=0)     # 后者供 KL 正则

def forward(self, images):
    regularizer = self.classifier[1:](self.domain_concept_projection)
    weights, _ = self.get_domain_weights()
    if weights is not None:
        regularizer = regularizer * weights.view(-1, 1, 1)   # 逐 prompt 加权
    ...
```

**训练侧 KL + 每 epoch 权重诊断**（机制证据链）：

```python
# KL 正则: D_KL(q ‖ U) = log N − H(q), q = softmax(residual)
_, residual_softmax = self.model.get_domain_weights()
N = residual_softmax.size(0)
entropy = -(residual_softmax * (residual_softmax + 1e-8).log()).sum()
kl_loss = torch.log(torch.tensor(float(N))) - entropy
total_loss = cls_loss + alpha * orth_loss + beta * concept_loss + lambda_kl * kl_loss

# 每个 epoch 保存 (论文机制分析用):
#   reliability prior r_i / residual δ_i / prior weight w_i^prior / final weight w_i^final
#   H(q), max/min/std(w), Δw = w^final − w^prior (Top 上调/下调 prompt)
torch.save({...}, f"logs/weights/{run_name}/epoch_{epoch:04d}.pt")
```

### 2.4 解耦设计（如何保证"先验不被训练污染"）

四层解耦：**梯度**（prior 是 detach buffer，optimizer 看不见，梯度流不到）、**时间**（reliability 离线算一次，residual 在线学习）、**接口**（reliability 模块只输出数值向量，model 不关心其来源，度量可替换）、**概念**（前者回答"方向是否稳定"，后者回答"任务需要多大权重"）。另外 AdamW 的 weight_decay 把 residual 往 0（即先验）拉，是隐式的先验信任偏置。

### 8.3 顺带：Reliability Top/Bottom 语义分析

用真实类名 + 真实 prompt 算出的 reliability 分布（同时支撑第三章方法动机的实证）：

**CUB Top-10**（最可靠 prompt，全是经典视觉风格）：photo collage, collage, gouache painting, watercolor, silhouette photo, pastel drawing, pastel artwork, pencil drawing, silhouette, crayon drawing
**CUB Bottom-10**（最不可靠，全是比喻/模糊）：visual novel character, futuristic concept art, medieval manuscript, ancient rune, flower arrangement resembling, retro style, constellation resembling, comic character, album cover, anime style

**AWA2 Top-10**（同样是经典风格）：chalk pavement art, gouache painting, pastel drawing, silhouette photo, photo collage, charcoal sketch, pastel artwork, sepia photo, chalkboard sketch, painting on driftwood
**AWA2 Bottom-10**（同样是比喻/模糊）：visual novel character, retro style, abstract representation, anime style, constellation resembling, Egyptian hieroglyph, album cover, safety sign, Renaissance painting, ancient rune

**解读**：
- 经典视觉媒介（水彩/粉彩/炭笔/剪影/拼贴）→ reliability 高（方向在 200 类上稳定）
- 比喻/类别依赖描述（"a constellation resembling a {}"、"an album cover with a {}"）→ reliability 低（类间迁移方向不一致）
- CUB 与 AWA2 上高度一致的 Top/Bottom prompt 语义表明，该 reliability 指标主要捕获 domain prompt 在不同类别条件下形成稳定迁移方向的能力，并表现出明显的**跨数据集一致性（dataset-insensitive tendency）**

**直接论文可用**：第三章方法动机小节 + 第三章方法论述里"为什么 reliability 是有意义的先验"的实证素材。

### 8.4 对第四章方法的推导（基于诊断结果）

| 现象 | 对第四章的启示 |
|---|---|
| 平均 cos 0.33 不独立 | → 204 个 prompt 有共享结构，可压缩 |
| ~1% prompt 对 cos > 0.7 | → 存在局部冗余簇（local redundancy） |
| EV(32)=80%（τ=0.8 自适应） | → 204 → 32 维保 80% 能量，subspace 方法有动机；且 τ 同阈值跨数据集自动给接近维数 |
| EV(5)≈49% | → 存在少数 dominant global domain axes，值得做 PC top-loading 语义分析 |
| 跨数据集一致 | → 结构是 CLIP 空间固有属性，方法可跨数据集泛化 |

**结论**：专家推荐的 "Domain Prompt Structure → Subspace → Soft Projection → Invariant Head" 方案**有数据支撑**；m 采用 energy-threshold 自适应（m=m(τ)，τ=0.8 默认，消融 τ∈{0.6,0.7,0.8,0.9,0.95}），不写死维数；clustering 暂不加入（保留为"若 global subspace 实验不足，再升级 Mixture of Domain Subspaces"的第二阶段路线）。

### 9.3 第四章第一版模型实现（`clip_cbm_subspace`）

```python
class clip_cbm_subspace(nn.Module):
    """Domain Subspace Guided Invariant Classification (专家定稿版)"""
    def __init__(self, args, class_names, concept_names, domain_diffs,
                 tau=0.8, ch4_mode="full"):
        # ①② Structure Discovery + Adaptive Subspace:
        #   类平均 prompt 方向 → SVD → m = m(τ) → B = V[:, :m]  (完全由文本得到, 无 target image)
        dirs = domain_diffs.mean(dim=1).float()               # (204, 768)
        dirs = dirs / (dirs.norm(dim=-1, keepdim=True) + 1e-8)
        U, S, Vh = torch.linalg.svd(dirs, full_matrices=False)
        cum_ev = torch.cumsum(S ** 2, dim=0) / (S ** 2).sum()
        self.subspace_dim = int(torch.searchsorted(cum_ev, tau).item()) + 1
        self.register_buffer('domain_basis', Vh[:self.subspace_dim].T)  # (768, m)

        # ③ Soft Suppression: γ = σ(a), learnable scalar
        self.gamma_logit = nn.Parameter(torch.zeros(1))       # 初始 γ=0.5

        # ④ 双头: 原始头(辅助监督) + invariant 头(测试主输出)
        self.classifier = make_classifier()                    # h_o(z)
        self.inv_classifier = make_classifier()                # h_inv(z_inv)

        # DDO 等权正交正则保留 (与基线可比)
        self.domain_concept_projection = domain_diffs @ self.concept_embeddings.T

    def forward(self, images):
        z = normalize(self.clip_model.encode_image(images))   # CLIP embedding 层投影
        gamma = torch.sigmoid(self.gamma_logit)
        z_inv = z - gamma * (z @ self.domain_basis) @ self.domain_basis.T  # 软抑制
        concept_act, concept_act_inv = z @ C.T, z_inv @ C.T   # 双 concept bottleneck
        logits_ori = self.classifier(concept_act)             # 辅助
        logits_inv = self.inv_classifier(concept_act_inv)     # 测试只用这个
        regularizer = self.classifier[1:](self.domain_concept_projection)  # DDO 等权
        return concept_act_inv, (logits_ori, logits_inv), regularizer

    # 训练: L = CE(logits_ori) + λ_inv·CE(logits_inv) + α·orth
    # 测试: 只用 logits_inv
```

CLI：`--CBM_type clip_cbm_subspace --ch4_mode {ddo|hardproj|softproj|headonly|full} --tau 0.8 --lambda_inv 1.0`

## 10. 第五轮反馈落实记录（2026-08-26，已全部完成）

### 10.1 专家检查点：DDO regularizer 与 invariant head 的作用对象 ✅ 已检查并修正

专家指出的问题**完全成立，且实际比描述的更严重**：原实现 `regularizer = classifier[1:](proj)` 只约束 original head，而测试用 inv_classifier。进一步检查发现：**在 CLIP frozen 的 CBM 中，两个头没有任何共享可学习参数（γ 只在 z_inv 路径），original head 的全部梯度（CE + DDO）都不流向测试路径**——即原 full/headonly 模式中测试头完全未被 DDO 约束，DDO 正则形同虚设。

**修正方案（专家三选项中的"两头都约束"）**：

```python
regularizer = self.classifier[1:](self.domain_concept_projection)          # L_DDO^ori
if self.inv_classifier is not None:
    reg_inv = self.inv_classifier[1:](self.domain_concept_projection)      # L_DDO^inv
    regularizer = regularizer + self.eta_ddo_inv * reg_inv                 # η 默认 1.0 对称
```

新增 `--eta_ddo_inv`（默认 1.0）。单头模式（ddo/hardproj/softproj）唯一头即测试头，原实现已一致。

**诚实记录**（写论文时需说明）：frozen-CLIP CBM 中 original head 的梯度独立性意味着它的作用是 (a) headonly 消融的结构基础 (b) 无投影参照分类器（其 source acc 与 inv head 对比可作为"投影代价"的分析素材），而非传统意义上的"辅助监督防止表示被破坏"（该机制在表示不可学习时不成立）。
