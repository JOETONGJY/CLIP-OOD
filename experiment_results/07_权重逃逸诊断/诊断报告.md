# δ–ℓ 耦合诊断报告：RW-DDO 的 weight avoidance 判别性检验

- **日期**：2026-11-20 ~ 11-21（外审驱动，见工作记录 GPT 讨论）
- **脚本**：`weight_loss_coupling_diagnosis.py`（缓存管线逐位等价复用，`save_model=False` 防检查点覆盖，`model_selection=final` → 结果写 `*_sel_*.json` 与主表零冲突）
- **诊断 run**：`CUB_prior_residual_sel_seed1`（100 epochs，严格 DG final target 55.96，best 监视 56.51@94）
- **数据**：`diag_CUB_prior_residual_sel_seed1.json`（静态统计 + 同 epoch 动态曲线 + 204 描述符逐项明细）+ `cls_snapshots/`（21 个分类器快照）

## 1. 问题与判别逻辑

外审推导：`L_DDO = Σ p_i ℓ_i, p = softmax(r+δ)` ⇒ `∂L/∂δ_i = p_i(ℓ_i − Σ_j p_j ℓ_j)`，梯度天然下调高损失描述符的权重（"weight avoidance"）。

旧机制证据 `corr(Δw, reliability) = +0.49/+0.51` 不能排除它——"权重有语义结构"与"残差逃避高损失约束"可以同时成立。本诊断回答三个递进问题：

1. 逃逸是否存在？（corr(δ, ℓ)）
2. 是否独立于可靠性先验？（偏相关控制 r）
3. 是否伤害**可信但困难**的方向？（象限分析）——这是"逃逸是否有害"的关键，因为下调不可靠且高损失的噪声描述符是合理的。

## 2. 方法要点

- 分类器快照每 5 epoch 保存 → ℓ(t) 为**真实同 epoch 值**（不重建历史分类器，遵守外审"不要用最终 ℓ 伪造 ℓ(t)"的意见）。
- 静态层：δ 与分类器取自同一收敛 state，天然自洽。
- **逐位复现确认**：诊断 run 的 δ(t) 轨迹与原始主表 run `CUB_prior_residual_seed1` 完全一致（t10=0.415 / t50=2.120 / t99=4.022）——本诊断分析的就是主表方法本身的训练动态，非代理；seed2/3 独立复现（corr −0.840 / −0.839）。

## 4. 判别性证据：可信且困难的方向被系统性下调

**象限分析（r 前 1/3 ∩ ℓ 前 1/3，n=9）**：全部 9 个描述符 dw < 0，mean(dw) = **−0.274**：

`a shadow puppet of` (−0.282) / `a silhouette photo of` (−0.281) / `a shadow silhouette of` (−0.277) / `a neon sign of` (−0.276) / `a sepia photo of` (−0.275) / `an advertising posters of` (−0.275) / `a neon artwork of` (−0.274) / `a silhouette of` (−0.273) / `a pop art of` (−0.259)

——这些是**与目标域（Painting）高度相关的可信媒介方向**（剪影/霓虹/棕褐色调/波普艺术等恰恰是油画域的常见风格），却被残差统一下调约 −0.27。

**ℓ-Top10（被回避的高损失方向）**：carved pumpkin / photo negative / blueprint / sepia photo / marble statue / steampunk / medieval manuscript / flower arrangement / futuristic concept art / bronze statue。

**ℓ-Bottom10（被上调的低损失方向）**：watercolor / gouache / acrylic / watercolor wash / pastel drawing / pastel artwork / sketch / crayon / postage stamp / oil painting。

**对旧机制叙事的修正**：上调集由"低损失"驱动（corr −0.84 几乎完全决定 δ 的方向）；"被上调词与目标域风格吻合"（旧叙事）是**伴随属性**——绘画类模板对 painting 目标域的正交约束天然容易满足（低 ℓ），于是既被逃逸机制上调、又恰好与目标域吻合。旧证据 corr(Δw, r) = +0.51 是"跟随先验 + 逃逸损失"两个机制的共同产物。

## 5. 动态层（同 epoch 真实值）

- corr(δ(t), ℓ(t))：epoch 5 已达 **−0.879**，此后稳定在 −0.83 ~ −0.88 —— **逃逸在最初几个 epoch 即锁定**，早于任何有意义的精度形成。
- |δ(t)| 从 0.03 单调增长至 4.02；mean ℓ 从 0.374 升至 0.928（分类器对域方向的整体响应在增大，同时权重持续向低损失方向倾斜）。
- 三个 seed 独立一致（corr(t99)：−0.837 / −0.840 / −0.839）。

## 6. 判定（按 2026-11-20 预注册框架，不作二元判决）

1. **逃逸现象：成立**。偏相关控制 r 后仍为 −0.77，且在高可靠半区内部同样成立（−0.83）。这不是先验的简单放大。
2. **有害方向存在**：9 个可信且困难的目标域相关方向全部被下调。"逃逸 → 泛化损失"的因果链**尚未建立**——下调它们可能无害（约束冗余）也可能有害（放弃了本可消除的域偏移），需要干预实验判定。
3. **对论文的影响**：第三章机制叙事须修正——不能将残差单一正向地叙述为"学习目标域需要的修正"；corr(Δw, r) = +0.51 的表述应改为"先验跟随与损失逃逸两机制的叠加"。
