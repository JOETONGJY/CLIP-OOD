# E3 方案 B：簇级分组去冗余（grouped RW-DDO）+ 注入扰动实验 — 完整报告

- **日期**：2026-11-21；**驱动**：`e3_grouped_injection_experiment.py`（预注册、断点续跑、严格 DG final、save_model=False、json 独立 tag 零冲突）
- **背景**：07 诊断证实 C-1 去冗余的"相对冗余度"修正是 softmax 下的数学空操作；E1 否证方案 A 后，第三章剩余改进路径为修复冗余机制。

## 1. 方法（grouped RW-DDO）

- **聚簇**：类平均域方向 |cos| > θ=0.9 的连通分量（single-linkage 近似重复族）。θ 唯一依据 = 离线相似度分布，不按目标精度调。干净 204 描述符 → CUB 192 簇 / AWA2 195 / LADV 193 / PACS 194（多成员簇 8~11 个，最大 3，涉及 17~23 个描述符）。
- **权重**：`w_i = Q_g(i) · q_i|g · (N/Σw)`，簇级 `Q_g = softmax(mean_r_g + Δ_g)·G`（Δ_g 为 G 维簇级可学习残差），簇内 `q = softmax(r)`。可训练参数 63,424 → 63,416（残差 204→192 维）。
- **可证性质（2026-11-23 第三版，按修正后单元测试精确化；此前两版表述均被单测收紧）**：
  ① **相对份额结构（单元素簇复制）**：被复制簇**合并份额精确不变**（0.133500→0.133500）；其余全部方向的份额**机器精度级不变**（max|Δp| ≤ 1.5e-8）；全部变化严格限制在被复制簇内部——复制体均分原成员份额（q 各 1/2）。即复制对 DDO 加权分布的影响被完全限制在其所属簇内，不外溢。
  ② **多元素簇内复制**：经簇均值再分配（R_g 变化）产生二阶微扰——簇外方向 max|Δp| ≤ 1.9e-4、合并份额微变 ≤0.1%（单测 B）。
  ③ **绝对权重**：mean(w)=1 校准使全体权重乘 (N+K)/N 因子（不影响相对分配）；离线份额实验 grouped ×1.139 ≈ 229/204=1.1226 即该因子（差 1.4% 为②的多元素效应）。
  ④ 全单元素簇时**严格退化回 RW-DDO**（逐位相同）。
  故定位表述为"**抑制重复计权**"（`tests_grouped_weights.py` / `invariance_test.json`）。

## 2. 离线机制实验（判据③，零训练，CUB 注入 25 个精确重复）

注入协议：25 个基描述符（预注册均匀索引 4,12,…,196）首字母大写变体；CLIP BPE 分词小写化 ⇒ token 级完全相同，cos = 1.0000（比 C-2 的 cos≈0.99 更纯净，无变体语义漂移混淆）。

> 注：grouped 行 ×1.139 中的大部分是全局校准因子 229/204=1.1226（见 §1 性质②），即注入后相对份额结构几乎不变——这正是复制不变性质的实验体现，膨胀倍数不应被解读为"仍有 14% 重复计权"。（原报告初稿 ×1.840/×1.998 两行同理含全局因子，但组间对比结论不变。）

| 加权公式 | 干净基25份额 | 注入后50份额 | 膨胀倍数 |
|---|---|---|---|
| 原 RW-DDO | 25.19 | 50.35 | **×1.998**（复现 C-2 的 ×2.000） |
| C-1（相对量+topk5） | 25.71 | 47.29 | ×1.840 |
| **grouped（本方案）** | 25.69 | 29.26 | **×1.139** |

残差 ×1.139 来自簇级 softmax 的再平衡（非复制驱动）。**判据③满足**（预期 ×1.0~1.2）。

## 3. 训练实验（严格 DG final，sel_target_acc，同 seed 配对）

**干净场景（grouped vs RW-DDO，判据①：不伤）**

## 4. 判定与结论

1. **判据① 满足 / 判据③ 满足 / 判据② 不满足**。机制层（份额 ×2.0→×1.14）完全有效，但机制修正**没有转化为精度差异**——因为在冻结 CLIP + 固定分类头的高维表示中，被膨胀的份额被环境自然吸收，冗余注入在干净基准协议下根本不伤精度。
2. 这是 C-2 结论（2026-11-12：扰动代价在噪声内）的**第二次独立确认**，且本次用了更纯净的注入（精确重复）、更严格的协议（严格 DG + 配对 seed）与真修复机制（抑制重复计权：单元素簇复制下相对份额严格不变，见 §1 性质①）。结论升级为定论：**在此任务设定下，描述符集合冗余不是精度瓶颈**。
3. **对论文的定位建议**：grouped **替换** C-1 成为第三章鲁棒性组件的最终形态——C-1 相对量公式是数学空操作（07 诊断），grouped 是真机制：两条可证数学性质 + 离线份额证据（×1.14 vs ×1.84 vs ×2.0）+ 干净精度无损（±0.06）+ 注入精度无损。精度增益主张继续不提出（诚实定位），组件价值 = 结构正确性 + 扰动下的权重分配正确性。
4. 写作素材：组件演化链（手调二值 → 可靠性加权 → C-1 冗余惩罚（发现空操作缺陷）→ grouped 聚簇修复）本身构成方法论严谨性的展示。
