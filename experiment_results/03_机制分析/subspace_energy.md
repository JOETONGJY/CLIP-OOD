# 诊断：图像特征在域子空间 B 上的能量占比（2026-09-11）

脚本: `subspace_energy_analysis.py`（可重复运行）
数据: CUB 缓存特征 (train 5990 / painting target 3047), B = SVD(204 prompts 类平均方向) 前 m=32 维 (τ=0.8)

## 结果

| 量 | 数值 |
|---|---|
| m(τ=0.8) | 32（与诊断报告 32/34 一致） |
| source 图像特征在 B 上能量占比 (mean) | **3.05%** |
| 同 (p90 / max) | 4.08% / 7.64% |
| 投影方向与 z 的余弦 (mean) | 0.173 |
| target(painting) 能量占比 (mean) | **4.73%** |
| source−target 能量差（域信号强度） | +1.68% |

## 解读
1. 域 prompt 方向张成的子空间与图像特征空间**几乎正交**（能量 ~3%）——
   文本导出的"域迁移方向"主要活在图像嵌入锥之外。
2. 因此 `z_inv = z − γ·BBᵀz` 在 γ≈0.5 时只改动特征 ~1.5% 能量：
   - softproj（γ 可学习）≈ DDO（56.12 vs 56.14）：软抑制退化为"几乎不抑制"
   - hardproj（γ=1）掉 0.92：把 4-5% 能量（含类别相关信息）硬删有害
   - γ 学习轨迹不动（0.4999→0.4966）：扰动太小, 梯度信号弱
3. painting 域特征比 source 多 1.68% 能量落在 B 内 —— 域信号**存在但很小**,
   这是"语言 prompt 方向 ≠ 图像域变化方向"的直接几何证据。

## 对论文的含义
第四章"子空间软抑制"在 CUB 上收益受限有明确的几何原因（可量化、可复现）。
该分析本身是论文可用的负结果/机制分析素材；AWA2（clipart）待对比。
